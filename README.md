# Мой портфель

Личный сайт учёта инвестиционного портфеля по бумагам KASE. Требования описаны в [PRD.md](PRD.md).

**Живая версия:** https://claude.ai/artifact/RsvwtLPDbG5t6ugasCuj6k (приватная, открывается в вашем аккаунте Claude).

## Структура

| Путь | Что это |
|---|---|
| `PRD.md` | Требования к продукту |
| `site/index.html` | Исходник страницы. Публикуется как claude.ai artifact с возможностями `db` и `user` |
| `data/market-latest.json` | Снимок документа `market/latest`: курс Нацбанка и цены KASE на 26.11.2026 |
| `data/portfolio-main.json` | Пример формата документа `portfolio/main` (не ваши покупки) |
| `docs/` | Сборка для GitHub Pages: страница + снимок цен |
| `scripts/build-pages.sh` | Пересобирает `docs/` из `site/index.html` и `data/market-latest.json` |

## GitHub Pages

Публичная копия сайта собирается в `docs/`. В ней нет хранилища Claude, поэтому:
- покупки хранятся только в браузере, где их внесли;
- цены и курс берутся из `docs/data/market-latest.json` — это снимок, обновляйте его вместе с `data/`.

После изменений: `sh scripts/build-pages.sh`, затем коммит и push.
Включение: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/docs`.

## Как это работает

- **Покупки** хранятся в базе артефакта, в документе `portfolio/main`, и копируются в `localStorage` браузера.
- **Цены и курс** лежат в документе `market/latest`. Страница не может сама ходить на kase.kz и nationalbank.kz, поэтому их обновляет Claude по запросу «обнови цены».
- **Расчёты** (п. 4.3 PRD): средняя цена, потрачено, стоимость, прибыль, доходность и годовая доходность при сроке владения от 90 дней. Покупки без цены помечаются «ждёт цену» и не входят в прибыль и доходность.

## Обновление

- Изменили `site/index.html` → попросите Claude опубликовать его на ту же ссылку.
- Новые цены → попросите Claude «обнови цены». Он запишет их в `market/latest`, и страница обновится сразу.
